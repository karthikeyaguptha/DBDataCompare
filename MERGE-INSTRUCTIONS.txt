DATA SYNC CHECK v1.7.2 INSTALLATION BUNDLE

1. Copy these files into the root of the Data Sync Check repository.
2. Merge README-v1.7.2.md into the existing README.md; do not keep two competing README files in the final repository.
3. Confirm config\launcher.env points to the real Python server entry point. Default: app.py.
4. Compare requirements-runtime.txt with the existing requirements.txt and add any application-specific runtime dependencies that are genuinely imported by the code. Keep Python 3.13 and binary-only compatibility.
5. Add the lines from .gitignore.additions to the repository .gitignore.
6. Run repair.bat on a clean Windows test machine.
7. Confirm setup completes even when the Microsoft SQL Server ODBC driver is absent; this should be a warning, not a failure.
8. Install the ODBC driver manually and validate SQL Server connectivity.
9. Execute the Git checkpoints in GIT-CHECKPOINTS.md.

IMPORTANT:
This bundle contains the complete installation layer, but it cannot infer every third-party module imported by application source files that were not supplied. Preserve additional validated runtime dependencies from the existing project when merging requirements-runtime.txt.
