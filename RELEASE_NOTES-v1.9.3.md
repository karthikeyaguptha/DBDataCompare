# Data Sync Check v1.9.3

## Reusable Tables Selection

- Renames Portable Template to **Reusable Tables Selection**.
- Makes Reusable Tables Selection the default save type.
- Keeps connection-specific selections available for exact database pairs.

## Reconciliation selection

- Adds a checkbox column to the reconciliation table.
- Selects all valid common tables by default.
- Adds a Select All checkbox with partial-selection feedback.
- Allows users to remove or restore individual tables before applying.
- Keeps one-sided, missing, and ambiguous rows visible and disabled.
- Applies the confirmed subset directly to Step 2, ready for comparison.

## Simplified controls

- Removes saved-selection JSON import and export.
- Gives the recovered space to wider saved-selection controls.
- Preserves comparison, pagination, profiles, reports, themes, and stop behavior.
