# Data Sync Check v1.9.5

## Reusable table selection refinements

- Aligns every reconciliation checkbox in a fixed-width selection column.
- Makes each reconciliation result tag a clickable filter.
- Shows a clear active state on the selected result filter.
- Applies the reconciliation master checkbox only to visible, selectable rows.
- Adds **Edit reusable selection** beside the Step 2 selection count.
- Reconciles the selected reusable set again when reopened.
- Preserves the currently applied Step 2 selection as the modal's checked state.
- Applies newly checked or unchecked rows directly back to the main table grid.

## Scope

- Preserves comparison execution, one-sided table behavior, pagination, profiles,
  reports, themes, saved-set storage, and stop controls.
